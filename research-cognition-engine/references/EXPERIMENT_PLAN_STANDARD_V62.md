# Experimental-design deliverable standard (no execution)

Each recommended hypothesis must specify: scientific problem and causal/algorithmic mechanism; supporting and contradictory papers (page quotes); nearest prior art with genuinely distinct proposed change; objective and falsifier; datasets with availability and train/validation/test split; compatible baseline algorithms and control conditions; metrics, ablations, robustness tests and sensitivity analyses; statistical repetitions and fair comparison policy; compute/time expectations; risks, stopping conditions, evidence gaps, and user-approval status. Do not run implementation code, data preprocessing, training, numerical simulation, or evaluation. Do not report hypothetical gains as measured values. Status is `PLANNED_NOT_EXECUTED`.
