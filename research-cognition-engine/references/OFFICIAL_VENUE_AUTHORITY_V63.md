# Official annual venue authority check

On a project's first run in each local calendar year, query the latest publicly accessible official Clarivate JCR release notice, the official CCF recommendations/corrections and the Chinese Academy of Sciences journal classification publication policy. Save authoritative URLs, observed dates, release edition, access limitations, response hashes and a same-year cache. A confirmed release announcement is not proof that any individual journal belongs to Q1/Q2 or a CCF category. Do not bypass JCR institution access. CAS stopped releasing new partitions from 2026; the 2025 edition is historical, not current 2026 ranking. A failed official request means `PARTIAL` rather than fabricated verification; browsing/reading can continue with venue rankings explicitly unverified.
