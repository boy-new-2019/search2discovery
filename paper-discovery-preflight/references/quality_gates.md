# Discovery quality gates

Only verified metadata (real OpenAlex work identity/title/authorship/date and source where present) may enter counted candidate lists. Deduplicate by DOI, title and OpenAlex work identity. Prefer recent three years, expand to earlier papers when genuine supply is insufficient, and report all shortfalls. A metadata record is not a read source. Legal OA PDF verification requires public HTTPS, appropriate byte signature, bounded size, extractable text and file integrity. Official journal or conference tier claims require separate official evidence.
