# Discovery preflight installation

Use the full RCE v6.6 standalone installer instead of separately applying an old discovery addon. Open the project in Codex Desktop and invoke `$research-cognition-engine` with the user's topic. Ensure the topic-specific English query set has been reviewed by a real subagent before beginning OpenAlex retrieval. A valid OpenAlex key may improve public quota access but cannot guarantee papers or premium subscriptions. No paywall bypass or fabricated bibliography is allowed.
