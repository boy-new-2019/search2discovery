# Project skills and release notes

- The public entrypoint is `$search2discovery`; internal engine versioned paths are compatibility interfaces.
- Distinguish candidate-record targets from achieved retrieval counts, metadata from full-text evidence, and offline tests from live Codex or scientific validation.
- PyMuPDF is optional and AGPL-3.0/commercial; `pypdf` is the permissive PDF text-extraction fallback. Neither library is vendored.
- For a bilingual GitHub landing page, place Simplified Chinese first, retain a complete English section, and add in-page language links.
- Before publishing, inspect the exact staged file set, run secret/data scans, review `git diff`, and verify the configured license and rights notes.

- Runtime repairs: preserve the immutable v4.4 manifest and use a separately verified hash overlay for declared source patches. Enforce LF checkout for byte-sensitive manifests.
- Windows prompt writers must use explicit LF; legacy signed prompt text may have CRLF on disk. Keep Unicode character budgets separate from UTF-8 bytes and retain historical over-reservations.
- Budget feasibility precedes optional breadth. Local caps are not provider quota. Ready core reading must not be starved by scientific questions misclassified as acquisition gates.
- New topic contracts require a signed final route/method card or an independently reviewed no-viable conclusion. Never recommend a candidate rejected by prior-art reviewers.
- Personal Skill bootstrap must work without the original repository path; test from an isolated personal directory with all four siblings.
- Python 3.12 Windows executable discovery applies PATHEXT rules to fixture paths; use an actual Python executable while retaining real subprocess argument and isolated-directory checks.

## Live campaign compatibility repairs

- Win32 nested answer/receipt paths require extended filesystem paths; preserve logical IDs and declare historical-engine utility changes in the separate hash-bound overlay.
- Reader-normalized PDF quotations must map back to exact original-page spans before entering the stricter memory store; retain native and literal quotation provenance.
- Preserve immutable selection-report bytes in evidence-gain events, reselect after new screening, and forward actual independent captain answers through the public entrypoint.
- Metadata sufficiency, reviewed query-pass coverage, genuine fulltext reading, and independent scientific conclusion are separate gates. A missing DOI is a task-local negative lookup, not whole-source failure or successful query coverage.

- For large cognition memories, pack whole source-balanced records and retain a hash-bound complete index. Pin linked evidence; FINAL needs actual committed plans and novelty objections, while independent novelty reviewers remain blinded.

- Fulltext task selection counts evidence by work and deduplicates PDF/source aliases. Prefer already anchored works before download-only files, then lower covered works; keep download-only startup and the complete lookup index available. This is evidence routing, not a scientific quality verdict.

- Unicode source-span alignment must account for whole-string composition and canonical reordering. Decomposition offsets plus local original-reader equivalence recover exact source spans without relaxing quotation checks.
- Original reader synthesis can outgrow its fixed prompt limit after independent evidence fusion. Keep whole balanced records, one primary evidence record per source row, untouched mandatory instructions and vetoes, and a complete immutable hash-bound index; never raise caps or count indexed previews as scientific review.

- Prioritize an already started cognition cycle over optional heuristic question searches, while retaining unread-source gates and mandatory hypothesis-specific prior-art search. Keep deferred questions available for an explicit later search.
