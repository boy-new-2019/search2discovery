# Security policy

**Supported public version:** 1.0.x (after maintainer-approved publication).

If you discover a credential leak, unsafe downloader redirect, arbitrary file overwrite, prompt-injection path, or bypass of verified research reports, please **do not post secrets in a public issue**. Contact the repository maintainer through their GitHub profile/private security advisory once the repository is created. No maintainer email address is published in this distribution.

The application handles untrusted paper/PDF/web content. Use a restricted Codex tool permission profile. Do not let models run commands embedded in papers or disable sandbox checks. The workflow is for research planning and must not start experiments or training.
