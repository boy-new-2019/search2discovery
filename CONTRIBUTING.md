# Contributing

Contributions that improve evidence provenance, testability, reproducibility, user documentation, and resource efficiency are welcome. Please open an issue describing the problem and a minimal, **public-domain or appropriately licensed** test case before major changes.

1. Do not include private research papers, credentials, personal `goal.md`, screenshots containing personal information, or user workspace outputs.
2. Preserve five distinct core-paper reading passes, independently sourced audit gates, novelty-risk uncertainty flags, no-experiment policy, and the requirement for actual independent model threads.
3. Add a deterministic offline regression test for behavior changes and describe any compatibility migration.
4. Run the five test commands in `README.md` before proposing a pull request.
5. Keep internal prompts/notes in concise English, exact original-paper quotations in their source language, and final researcher presentation in Chinese.

This repository is a research-support workflow, not an academic authority or medical/legal advice service.
